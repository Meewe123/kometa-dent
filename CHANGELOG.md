# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — на [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2026-10-02

Полная переработка после аудита ([AUDIT.md](AUDIT.md)).

### Безопасность

- Список записей пациентов больше не открыт всем: админ-API требует токен, сравнение за постоянное время, ограничение неудачных попыток.
- Ошибки сервера больше не показывают стектрейс.
- Пользовательский ввод экранируется в уведомлениях Telegram.
- Строгая Content-Security-Policy, заголовки helmet, закрыт CORS.
- Удалены неиспользуемые зависимости с уязвимостями (nodemailer, body-parser, cors); `npm audit` — 0 уязвимостей.

### Исправлено

- Двойная запись на одно и то же время.
- Запись на прошедшее время, несуществующую дату, время вне сетки, неизвестную услугу.
- Мобильное меню схлопывалось после прокрутки, кнопку закрытия перекрывало само меню.
- Несуществующие страницы и файлы отдавали главную с кодом 200.
- Мигание языка при загрузке и непереведённые сообщения.
- «Звёздный» фон рисовался только в углу экрана, знаки «+» у цифр уезжали на новую строку.
- Минимальная дата в форме считалась в UTC, а не по Ташкенту.

### Добавлено

- Узбекская версия по отдельному адресу `/uz/` с серверным рендерингом.
- Выбор дня и времени кнопками со скелетоном загрузки, пустым состоянием и повтором при ошибке.
- Панель администратора `/admin`: записи по дням, подтверждение и отмена.
- Демо-режим `npm run demo`: данные в памяти, тестовые записи, плашка «демо».
- Живые часы по Ташкенту в первом экране.
- Страница 404, `robots.txt`, `sitemap.xml`, `hreflang`, Open Graph, разметка schema.org.
- Тёмная тема по системной настройке.
- Тесты: 61 юнит- и API-тест, 17 браузерных (Playwright) с проверкой доступности (axe).
- GitHub Actions, ESLint, Prettier, Dependabot, Dockerfile, конфигурация Render.

### Изменено

- Новая дизайн-система: шрифты Literata и Golos Text, палитра с одним акцентом, шкалы размеров и отступов, токены в CSS.
- Тексты переписаны без рекламных клише; факты о клинике сохранены.
- Сервер разделён на модули; хранилище пишет файл атомарно.
- Шрифты подключаются с собственного сервера и урезаны до нужных символов (~230 → ~98 КБ).

### Удалено

- Загрузочный экран, анимированное «звёздное небо», счётчики цифр, пульсирующая кнопка.
- Встроенная карта Google с неверными координатами — вместо неё ссылки на Яндекс Карты, Google Карты и 2ГИС.
- Неиспользуемый эндпоинт `POST /api/contact`.

## [0.1.0] — 2026-06-15

Первая версия: одностраничный сайт на Express, форма записи с сохранением в JSON-файл, уведомления в Telegram, переключатель RU/UZ.
