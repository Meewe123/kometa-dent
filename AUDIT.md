# Аудит проекта Kometa Dent

Дата: 2 октября 2026. Состояние: коммит `94d2ae0`.

Что это: одностраничный сайт стоматологической клиники в Ташкенте (RU/UZ) с формой онлайн-записи. Бэкенд на Express сохраняет записи в JSON-файл и отправляет уведомление в Telegram.

Как проверял: прочитал весь код, запустил сервер локально, отправлял запросы к API через `curl` (включая некорректные), открывал страницу в Chromium на 1440px и 360px, считал контраст цветов по формуле WCAG, запускал `npm audit`.

---

## 1. Что сделано хорошо

- **Работающий сценарий.** Форма записи отправляет данные, сервер их сохраняет, клиника получает уведомление в Telegram. Это настоящий продукт, а не макет.
- **Два языка.** Есть русский и узбекский, выбор языка сохраняется.
- **Свободные слоты.** Сервер отдаёт занятые слоты, и форма показывает их как недоступные.
- **Основа защиты.** На API стоит ограничение частоты запросов (rate limit).
- **Есть зачаток дизайн-токенов.** Цвета, радиусы и тени вынесены в CSS-переменные.
- **Без тяжёлых фреймворков.** Страница быстро грузится, код легко читать.
- **Секреты не в коде.** Токен Telegram берётся из переменных окружения, `.env` в `.gitignore`.

## 2. Критичные проблемы (безопасность и данные)

| # | Проблема | Где | Чем грозит |
|---|---|---|---|
| S1 | **`GET /api/admin/appointments` без авторизации.** Любой, кто знает адрес, получает имена и телефоны всех пациентов. | `server.js:150` | Утечка персональных данных пациентов. Для медицинской организации это серьёзное нарушение закона о персональных данных. |
| S2 | **Утечка стектрейса.** Если отправить `name: 123` или битый JSON, сервер падает с ошибкой 500 и показывает в ответе путь к файлам и внутренности Express. | `server.js:74`, нет обработчика ошибок | Атакующий узнаёт устройство сервера. Пользователь видит «сломанный» ответ. |
| S3 | **HTML-инъекция в Telegram.** Данные пользователя вставляются в сообщение с `parse_mode: 'HTML'` без экранирования. | `server.js:88` | Можно подсунуть ссылку в уведомление администратору. Если в имени есть `<` или `<script>`, Telegram отклонит сообщение, и клиника **молча не узнает о записи**: ошибка проглатывается (`req.on('error', () => {})`). |
| S4 | **Нет валидации типов и длины.** Можно записать в базу объект вместо строки, мегабайтный комментарий, любую «услугу», прошедшую дату, время `03:00`. | `server.js:61–83` | Мусор в базе, переполнение диска, поломка админки. |
| S5 | **Двойная запись на одно время.** Сервер не проверяет, свободен ли слот. Два человека могут записаться на 10:00 одного дня. Проверено: оба запроса вернули `success: true`. | `server.js:61` | Главная функция продукта работает неправильно. |
| S6 | **Уязвимые и лишние зависимости.** `nodemailer` (2 high) и `body-parser` подключены, но нигде не используются. У `qs` (через express) есть moderate-уязвимости. | `package.json` | `npm audit`: 5 уязвимостей. |
| S7 | **CORS открыт для всех доменов** (`cors()` без настроек), есть заголовок `X-Powered-By`, нет заголовков безопасности (CSP, `X-Content-Type-Options` и др.). | `server.js:28` | Любой сайт может отправлять запросы к API от имени пользователя. |
| S8 | **Неатомарная запись в файл.** Если процесс упадёт во время `writeFileSync`, `appointments.json` повредится, и сервер перестанет запускаться (`JSON.parse` упадёт). ID = `Date.now()`, поэтому возможны совпадения. | `server.js:56`, `:72` | Потеря всех записей. |

## 3. Баги

| # | Баг | Где |
|---|---|---|
| B1 | **Мобильное меню ломается после прокрутки.** У шапки при скролле появляется `backdrop-filter`, а он меняет поведение `position: fixed` у вложенного меню. Меню сжимается до полоски 52px. Кнопка-бургер оказывается под меню, закрыть его можно только кликом по ссылке. Проверено в Chromium на 360px. | `style.css:127`, `:1189` |
| B2 | **«Звёздное небо» рисуется только в левом верхнем углу.** `<canvas>` не растягивается через `inset: 0`, его размер остаётся 300×150. | `style.css:236`, `main.js:41` |
| B3 | **«+» и «/7» у цифр в hero уезжают на отдельную строку** из-за `flex-direction: column`. | `index.html:96`, `style.css:304` |
| B4 | **Несуществующие страницы возвращают главную с кодом 200** (soft 404), отсутствующие файлы тоже (`/assets/clinic.jpg` → HTML). Нет страницы 404. | `server.js:159` |
| B5 | **«Работаем 24/7», но записаться можно только на 09:00–20:30.** Нигде не объяснено, что ночью помощь только экстренная и по телефону. | `server.js:135`, тексты |
| B6 | **Сегодняшние прошедшие слоты доступны.** В 15:00 можно записаться на 09:00 сегодня. | `server.js:126` |
| B7 | **Минимальная дата считается в UTC.** С 00:00 до 05:00 по Ташкенту в календаре можно выбрать вчерашний день. | `main.js:160` |
| B8 | **Переключение языка неполное.** Сообщения об ошибках, «Загрузка…», «(занято)», ответы сервера, `aria-label`, `<title>` и `meta description` всегда на русском. | `main.js`, `server.js` |
| B9 | **Мигание языка.** HTML на русском, а узбекский применяется только после загрузки скрипта, поэтому текст на секунду меняется. | `i18n.js:300` |
| B10 | **Искусственная задержка загрузки.** Лоадер скрывает уже загруженную страницу ещё на 800 мс после `load`. | `main.js:8` |
| B11 | **Без JavaScript страница пустая.** Все блоки с `.reveal` имеют `opacity: 0` и проявляются только через JS. | `style.css:1113` |
| B12 | **Карта ведёт не туда.** URL встраивания Google Maps собран вручную (`1s0x0:0x0`, `4v1234567890`) и указывает на условный центр Ташкента, а не на клинику. Кнопка «Оставить отзыв» ведёт на `maps.google.com`. | `index.html:485`, `:362` |
| B13 | **Мёртвый код.** `POST /api/contact` не используется ни одной формой. Ключи `hero.cta2`, `reviews.google`, `form.loading` не используются. Список слотов продублирован на клиенте и сервере. | `server.js:107`, `main.js:195` |
| B14 | **Анимации не учитывают `prefers-reduced-motion`.** Canvas крутится бесконечно, даже когда hero не виден. Кнопка звонка постоянно пульсирует. | `main.js:111`, `style.css:1099` |
| B15 | **Год в копирайте зашит** (`© 2024`). | `index.html:534` |

## 6. Дизайн: признаки «ИИ-стиля»

| # | Признак |
|---|---|
| D1 | **Шаблонная структура:** hero с цифрами-счётчиками → сетка карточек с иконками → «4 шага» → карточки врачей → 3 отзыва со звёздами → CTA. Самая узнаваемая схема сгенерированного лендинга. |
| D2 | **Эстетика «тёмный космос + золото»:** звёздный canvas, кометы, свечение (`--shadow-gold`), пульсирующая кнопка, золотые градиенты-полоски, `backdrop-filter: blur` на шапке и кнопке. |

| D4 | **Одинаковые карточки повсюду:** одинаковые радиусы (16px), рамки, тени и `translateY(-6px)` при наведении у услуг, врачей и отзывов. |
| D5 | **Шрифты по умолчанию для «премиума»:** Inter (5 начертаний) + Cormorant Garamond курсивом в каждом заголовке («Полный спектр *стоматологических услуг*»). Шрифты грузятся с Google Fonts и блокируют отрисовку. |
| D6 | **Палитра без системы:** 3 оттенка navy, 3 оттенка золота, бирюзовый в градиенте, плюс захардкоженные `#E5E9EF`, `#E74C3C`, `#f5f5f5`, `rgba(...)` в 40+ местах. Нет шкалы отступов и типографики. |
| D7 | **Цифры-счётчики «накручиваются»** при прокрутке. Это декоративный приём, к тому же для непроверенных цифр. |
| D8 | **Плейсхолдеры вместо фото.** Силуэты вместо врачей и иконка вместо фото клиники. Сайт выглядит недоделанным. |
